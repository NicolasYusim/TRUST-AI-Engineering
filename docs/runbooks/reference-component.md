# Reference component runbook

This is an illustrative runbook target for repository manifests. A deployment
must replace it with an owned operational runbook.

1. Identify the component and run ID.
2. Stop or disable side effects if authorization, tenant isolation, or audit
   integrity is uncertain.
3. Select the declared fail-closed or degraded mode.
4. Preserve privacy-safe evidence references.
5. Notify the manifest owner.
6. Record the incident, affected versions, recovery decision, and follow-up.
